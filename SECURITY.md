# Security

Please report security issues privately, not as a public GitHub issue.

Contact: security@vecmo.dev (placeholder — to be confirmed).

Include what you found, how to reproduce it, and the affected version/commit.

## Scope

In scope: this editor (the code in this repository) and the runtime code it exports (`*.runtime.js`, `webgl-player.js`).

Out of scope: the vecmo.dev hosted service (accounts, billing, cloud storage, job processing). That backend is a separate, private codebase and is not published here.
